# 练习使用多用电表 · 从一只表头到六个档位（11.5 可交互课件 · 第四版）

人教版必修第三册 11.5 的**设计与使用**课件：一只 Ig = 1 mA / Rg = 100 Ω 的表头，
怎么一步步设计成课本图 11.5-1 那台多用电表，然后真的拿它去测东西。

- **单文件 HTML**：零外链，断网可开，直接打开 `index.html`。
- **八幕 33 步**：情景（电工只有一只表头）→ 复习两条公式 → **量程的设计** → **刻度的设计**
  → **表笔的设计** → 欧姆挡 → **电路图怎么来的（最终电路图 = 你给的那张参考图）** → **真实使用**。
- **最终电路图**：虚线框表头组件（G + R₁ + R₂）+ 六触点旋转开关 + ③④ 电池与调零 + ⑤⑥ 串阻 + A/B 表笔。
  底栏「选择开关」逐档切换，**只有被选中的支路变亮、电流粒子只沿那一条走**，其余全部变灰虚线。
- **真实使用**：选对象 → 选挡 → 读数，带**接入误差**（R_V 有限）与**打表警告**；欧姆挡带断电/调零/中间读三条纪律。

固定参数：Ig = 1 mA · Rg = 100 Ω · Ug = 0.1 V · ⑤ 2.5 V（R₃ = 2400 Ω）· ⑥ 10 V（R₃+R₄ = 9900 Ω）
· ① 100 mA（R₁ = 1.1111 Ω）· ② 10 mA（R₁+R₂ = 11.1111 Ω）· ③ ×100（E 1.5 V / R内 1500 Ω）· ④ ×1k（E 15 V / R内 15 kΩ）。
