# 多用电表的设计与使用 · 从一只表头开始（11.5 可交互课件）

人教版选择性必修第三册 11.5 的**设计课**课件：一只 1 mA 表头，怎么一步步"设计"成多用电表。

- **单文件 HTML**：零外链，断网可开，直接打开 `index.html`。
- **八幕 30 步**：情景 → 复习 → **量程的设计** → **刻度的设计** → **表笔的设计** → 欧姆挡 → **电路图怎么来的** → 合成与六步使用。
- **可拖的连续量**：指针位置、电压/电流量程、表头内阻、被测电阻、调零、偏转比、倍率、选择开关位置。
- **三条主线**：量程是怎么定的（R = U/Ig − Rg、R = IgRg/(I−Ig)、推荐量程取最小 ≥2× 被测值的标准挡）；刻度怎么随量程改（刻度值 = f × 量程，分度只许 0.1/0.2/0.5，3 V 挡分度 0.1 V → 读到 0.01 V）；表笔为什么一红一黑（红进黑出；欧姆挡表内电池正极接黑笔，黑笔侧电势高）。
- **电路图 ↔ 实物一一对应**：`wireMap` 映射表 + 5 种接错的具体提示。

固定参数：Ig = 1 mA · Rg = 100 Ω · Ug = 0.1 V · E = 1.5 V · ×1k 挡 E = 9 V。
